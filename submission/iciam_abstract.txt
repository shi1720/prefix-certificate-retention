Retaining key-value states for language-model serving trades repeated computation against storage time. A cached block is usable as a prefix only when all preceding blocks are available, so independent hit accounting can overestimate savings. We introduce Prefix-Certificate Retention, an exact optimization model for static, grouped, reset-on-access timeouts on a finite request trace. Hit certificates encode local timeout thresholds and preceding-prefix prerequisites. With incremental memory-time costs, this construction yields a maximum-weight closure problem solvable by one minimum cut. We prove that observed reuse ages suffice to optimize over all nonnegative timeouts, giving a graph with size linear in the number of block lookups. A tree dynamic program handles ordered timeouts, while computable bounds certify the loss from this simpler restriction. Exhaustive small-instance checks and chronological replay of 39,632 public Mooncake requests validate the model. Ordered timeouts attain the unrestricted training optimum in 118 of 120 fixed-grid cases; heterogeneous profiles improve several held-out storage-reuse tradeoffs, with workload-dependent transfer. The results provide a tractable configuration oracle and auditable benchmark for prefix-cache retention, separating exact historical optimization from future-workload performance.
